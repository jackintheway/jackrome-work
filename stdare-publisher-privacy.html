ST. DARE Publisher: Privacy Policy

Last updated October 10, 2026

ST. DARE Publisher is a private tool the ST. DARE team (Allan Ishac and Jack Rome) uses to manage the ST. DARE YouTube channel. It isn't offered to the public.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to set titles, descriptions, tags, thumbnails, captions, privacy and schedules on the channel's own videos and to manage its playlists. It uses the YouTube Analytics API to read the channel's own viewing statistics.

Where your data goes

The tool runs on one computer the ST. DARE team controls. The sign-in and any statistics it reads are stored there. Reports may be reviewed with the help of an AI assistant (Claude, by Anthropic). Nothing is sold, shared with anyone else, or used for advertising.

Removing access

You can remove the tool's access at any time at myaccount.google.com/permissions.

ST. DARE Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
